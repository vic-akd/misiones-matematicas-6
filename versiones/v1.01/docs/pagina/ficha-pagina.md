# Misiones de matemáticas · 6.º de primaria (México) · v1.01

**Eslogan:** Matemáticas de 6.º para contestar en pantalla o imprimir y revisar juntos.

**Para quién:** familias y docentes de 6.º de primaria en México que quieren practicar todas las matemáticas del grado, con ayudas que bajan poco a poco.

**Cómo funciona**
1. Abre la página y elige una ficha.
2. Contéstala en pantalla y comprueba al momento, o imprímela en carta.
3. Si te equivocas, aparece una pista; al segundo error puedes ver la respuesta.
4. En papel, dobla la hoja y revisen juntos con el solucionario de abajo.

**Incluye:** 15 temas, 90 fichas, 270 ejercicios.

| Función | HTML |
|---|---|
| Elegir y ver ficha | Sí |
| Contestar en pantalla y comprobar | Sí |
| Mostrar respuestas | Sí |
| Imprimir o guardar en PDF (ficha, tema o todo) | Sí |
| Descargar el archivo | Sí |

Solo existe la versión HTML. Requisitos: un navegador actual (Chrome, Edge, Firefox o Safari).
